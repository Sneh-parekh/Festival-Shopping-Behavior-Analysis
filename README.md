# Festival-Shopping-Behavior-Analysis

🎉 Festive Shopping Behavior Analysis
📌 Project Overview

This project analyzes customer shopping behavior during festive seasons to help retail businesses make data-driven decisions. Using Python and MySQL, the project focuses on cleaning raw data, understanding customer patterns, and generating actionable business insights.

The goal is to improve revenue, customer retention, and marketing effectiveness during high-sales periods.

🎯 Business Problem

Retail companies experience a spike in sales during festivals but often lack clarity on:

Which customers drive the most revenue

How discounts impact profitability

Which products and segments perform best

How to retain customers post-festival

This project addresses these challenges through structured data analysis.

🧠 Objectives

Clean and prepare raw shopping data for analysis

Analyze customer demographics and purchasing behavior

Evaluate the effectiveness of discounts and subscriptions

Identify high-value customer segments

Store clean data in MySQL for further analysis and BI reporting

📂 Dataset Description

The dataset contains festive shopping transactions with information such as:

Customer demographics (Age, Gender, Location)

Product details (Category, Item, Size, Color)

Purchase metrics (Amount, Quantity, Discounts)

Behavioral attributes (Previous Purchases, Subscription Status, Shipping Type)

🛠 Tools & Technologies

Python: Pandas, NumPy

Database: MySQL

Data Handling: SQLAlchemy

Future Scope: Power BI / Excel dashboards

🔄 Data Cleaning & Preparation

Key steps performed:

Checked and confirmed no duplicate records

Handled missing values using statistical methods

Standardized categorical columns (Gender, Payment Method, Shipping Type)

Renamed columns for consistency and SQL compatibility

Removed unnecessary columns to improve analysis clarity

Created derived features such as Age Group

Reordered columns for better business understanding

Loaded clean data into MySQL database

📊 Key Insights

Repeat customers contribute significantly higher revenue

Discounts influence purchases but must be optimized to protect margins

Certain product categories dominate festive sales

Digital payment methods are preferred during festive shopping

Subscribers show higher loyalty and repeat purchases

💡 Business Recommendations

Boost subscriptions by offering exclusive festive benefits

Implement loyalty programs to retain repeat customers

Optimize discount strategies to balance sales and margins

Highlight top-rated and best-selling products in campaigns

Use targeted marketing based on age group and shipping preference

Improve checkout and payment experience to reduce cart abandonment
